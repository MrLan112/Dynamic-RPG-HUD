# Dynamic RPG HUD

**Версия 2.2.0 · Fabric · Minecraft Java 1.21.1 · только клиент · авторы: Mr_Lan123 и ipEtroIlIu**

Dynamic RPG HUD прячет хотбар и полоски состояния, пока они не нужны, и возвращает их, как только
что-то происходит. Каждый элемент можно перемещать, масштабировать и настраивать в визуальном
редакторе, а HUD нескольких популярных модов - так же.

Мод ставится только на клиент и ничего не двигает сам: каждый элемент стоит там, где его рисует
ванильная игра, пока вы его не переместите.

## Быстрый старт

1. Установите Fabric Loader и Fabric API, положите мод в папку `mods`.
2. Откройте настройки через **Mod Menu** (Моды → Dynamic RPG HUD → Настроить) или назначьте клавишу
   «Open Dynamic RPG HUD Settings» в управлении (по умолчанию она не назначена).
3. В режиме «Только по клавише» нажимайте **H**, чтобы показать или скрыть HUD.

По умолчанию работает автоматический режим: HUD скрывается, пока вы стоите при полном здоровье и
голоде или бегаете, и появляется, когда что-то происходит.

## За что отвечает каждая кнопка

### Главный экран настроек
* **Configure Elements** - открывает редактор расположения.
* **Fade-out Animation** - как HUD исчезает по умолчанию: плавное растворение, сдвиг вниз / вверх / влево / вправо, сжатие
  или мгновенное скрытие. Для любого элемента можно выбрать свою анимацию.
* **HUD Visibility Trigger** - **автоматический** режим или **только по клавише** (H).
* **Automatic Mode** - тонкая настройка автоматического режима (ниже).
* **Reset Everything** - сбрасывает все настройки (с подтверждением).
* **Done** - сохраняет и закрывает.

### Редактор расположения
Игра остаётся видна под тёмным полупрозрачным слоем, каждый элемент HUD показан рамкой.

* **Кнопка слоёв** (маленькая квадратная кнопка справа от «Reset All Positions») переключает
  **Слой 1** (по умолчанию) - сердца, броня, голод, хотбар, опыт, прицел и HUD других модов - и
  **Слой 2** - HUD, который виден не всегда: пузырьки воздуха, шкала прыжка лошади, здоровье
  животного и эффекты.
* **Перетащите рамку** мышью - элемент переместится.
* **Нажмите на рамку** - откроется панель элемента:
  * **X / Y** - смещение от обычного места (0 / 0 - как в ванили).
  * **Scale** - ползунок или число в процентах.
  * **Stay visible when HUD hides** - элемент не скрывается. У ванильных элементов выключено, у
    элементов других модов включено.
  * **Hide animation** - своя анимация для этого элемента или «как в общих настройках».
  * **Reset This Element** - сбрасывает только этот элемент.
  * **Прицел** нельзя двигать: можно менять размер, анимацию скрытия и то, скрывается ли он вообще
    (по умолчанию не скрывается).
  * У **пузырьков воздуха** три дополнительных переключателя: показывать пузырьки, пока вы под водой; показывать сразу, как только вы под
    водой (или только когда воздух начал убывать), и не скрывать, пока воздух не восполнится после
    выхода из воды (или скрывать сразу).
  * **Шкала прыжка лошади** всё время скрыта и показывается, только пока вы держите прыжок, до
    самого прыжка лошади. «Stay visible» отключает это.
* **Reset All Positions** - возвращает все элементы на места (с подтверждением).

### Экран Automatic Mode
* **Задержка перед скрытием** - сколько секунд HUD остаётся после последнего события: от 0,5 до 30
  секунд, по умолчанию 4.
* **Show HUD when...** - список переключателей (✓ включено, ✗ выключено), прокручивается колесом
  мыши. HUD появляется, когда происходит любое включённое событие: получение урона, лечение,
  утопление, урон от огня, горение, изменение голода, здоровья, брони или опыта, смена предмета,
  прокрутка хотбара, нажатие клавиши хотбара (даже для уже выбранного слота), атака, взаимодействие, прыжок, бег, приседание, подбор и использование
  предмета, открытие инвентаря, получение эффекта. Включены по умолчанию: урон, лечение,
  утопление, урон от огня, горение, голод, броня, смена предмета, прокрутка хотбара, клавиша хотбара, инвентарь,
  эффект.
* **Enable All / Disable All / Defaults** - быстрые пресеты для всего списка.

Важно: после задержки HUD скрывается, только если вы двигаетесь или здоровье и голод полные. Если
вы стоите с неполным здоровьем или голодом, HUD остаётся на экране.

## Поддерживаемые моды

Если установлен один из этих модов, его HUD появляется в редакторе как отдельная рамка: его можно
двигать, масштабировать, скрывать и задавать ему свою анимацию. По умолчанию HUD других модов
**не** скрывается.

| Мод | Что настраивается |
|---|---|
| Jade | подсказка |
| WTHIT | подсказка (вместе с фоном) |
| Xaero's Minimap | миникарта (рамка в редакторе приблизительная) |
| Sodium Extra | счётчик FPS / координаты |
| FPS - Display | счётчик FPS |
| Simple Voice Chat | значки голоса |
| MiniHUD | информационные строки |
| Overflowing Bars | полоски здоровья, брони и прочности (двигаются и скрываются вместе с ванильными Health / Armor) |
| AppleSkin и похожие | следуют за ванильным элементом, в который рисуют |

Ни один из этих модов не обязателен, и в мод они не встроены.

## Полезно знать
* Настройки хранятся в `config/dynamicrpghud.json`. Отправьте этот файл другу, чтобы поделиться
  настройкой.
* Поддержка модов сделана по их открытому исходному коду. Если мод обновился и его HUD перестал
  реагировать, сообщите в Discord.
* Есть русский и английский языки.
